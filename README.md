# Ster
Aster Products (Ster Consult) is a cosmetic formulation and product development consultancy helping beauty brands move from idea to compliant, market-ready products. The website is a fast, modern Next.js build focused on clarity, credibility, and converting visitors into consultation leads.
## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- React Hook Form + Zod
- Framer Motion (light animations)
- Vercel (deployment)

---

## Design
- Background: `#000000`
- Primary accent: `#9dcd5a`
- Text: white / muted gray
- Style: minimal, premium, scientific
- All interactive states use `#9dcd5a`

---

## Pages
- `/` – Home (hero, expertise, services, CTA)
- `/about` – About & mission
- `/services` – Service catalogue (accordion cards)
- `/contact` – Contact info + inquiry form
